# DataForSEO MCP

- **Källa:** [dataforseo/mcp-server-typescript](https://github.com/dataforseo/mcp-server-typescript), v3.1.3 (`package.json`), commit `1fc6d19`, 2026-10-02. Läst 2026-10-16 ur en klon: README i sin helhet. [DataForSEO, priser](https://dataforseo.com/pricing), läst 2026-10-16. API-dokumentationen på docs.dataforseo.com är inte läst sida för sida (⚠️).
- **Rättat 2026-10-16 efter översynen (`kunskap/research/2026-10-16_verktyg-och-skills-full-potential.md`):** byggsessionen har den värdade servern med OAuth, inte stdio med lösenord i miljön.
- **Licens:** servern Apache-2.0. Datan är en betald tjänst under DataForSEO:s villkor: minsta insättning 50 dollar, provkredit 1 dollar, inga abonnemang; sökordsdata från 0,0012 dollar per uppgift.
- **Vad det är:** DataForSEO:s officiella MCP-server och kommandoradsverktyg för deras API:er: sökresultat, sökordsdata (sökvolymer från Google Ads), bakåtlänkar, företagsdata och mer.
- **Hur det fungerar:** stdio som standard, eller HTTP lokalt eller som deras hostade server med OAuth. Fyra verktyg: tre för att söka i dokumentationen och `api_request`, som gör vilket autentiserat API-anrop som helst. I stdio-läget ligger inloggning och lösenord som miljövariabler (HTTP Basic). Byggsessionen använder i stället DataForSEO:s värdade server med OAuth, `https://mcp.dataforseo.com/v3/mcp`. En konfigurationsfil kan begränsa vilka fält som returneras.
- **Kvalitet och underhåll:** 254 ★, 15 bidragsgivare, senaste push 2026-10-02, fyra öppna ärenden och PR, bland dem #27 om att svaren överskrider modellens kontextfönster.
- **Det bästa vi kan ta:** bakåtlänkar till den gamla sajten per adress, så att omdirigeringskartan prioriterar adresser med länkar; sökvolymer som relativa jämförelser mellan sökfraser (→ `guide/2-3-struktur.md`, sökord).
- **Var det hamnar hos oss:** MCP som kräver konto, beskriven i skillen `omfattning`, `verktyg.md` och `inventering.md`. Inlagd i byggsessionen som den värdade servern med OAuth, men inte inloggad; väntar tills en sajt behöver datan (`BESLUT.md` 2026-10-16).
- **Passar vår stack?** Ja som lokalt verktyg. Sökvolymerna i små orter är låga och används bara relativt.
- **Risker och flaggor:** `api_request` kan göra vilket betalt anrop som helst; sätt en låg budget på kontot. Recensions- och företagsdata innehåller recensenternas namn (personuppgifter), och tjänstens rättsliga grund för Google-data är ⚠️ inte kontrollerad. Stora svar fyller kontexten (#27); begränsa fälten. I byggsessionen sker inloggningen med OAuth mot den värdade servern, så inget lösenord ligger i miljön. Servern står olåst i verktygslåset (`LAGE.md`).
- **Inloggning:** kräver ett DataForSEO-konto med insättning. Johnny skapar kontot; dokumentationen och README är publika.
