# Bolagsverkets API

- **Källa:** ⚠️ Bolagsverkets egna sidor (bolagsverket.se, portal.api.bolagsverket.se) visade en CAPTCHA vid försöket 2026-10-16, som tidigare 2026-10-13, och gick inte att läsa. Underlaget är tredjepartskällor i `kunskap/research/2026-10-15_kompetensluckor-anteckningar/lager-1-2-strategi-omfattning.md`, fråga 4: [otwarteAPI.pl](https://otwarteapi.pl/en/bolagsverket-se), [bolagsverket_ex på hex.pm](https://readme.hex.pm/bolagsverket_ex/0.1.0) och [Topograph](https://docs.topograph.co/essentials/sweden). En webbsökning 2026-10-16 gav regeringens beslut om ett tidsbegränsat undantag (högst två år från 2023) från kravet på avgiftsfrihet för grundläggande företagsinformation, men inget nyare officiellt besked.
- **Licens:** enligt tredjepart avgiftsfritt och utan avtal ("Use is free and requires no agreement"). ⚠️ Overifierat. EU:s genomförandeförordning om värdefulla datamängder (EU) 2023/138 kräver att grundläggande företagsuppgifter är avgiftsfria via API; ⚠️ texten gick inte att läsa på EUR-Lex 2026-10-16.
- **Vad det är:** Bolagsverkets API för värdefulla datamängder, lanserat 3 februari 2025 enligt rubriken på en nyhet som inte gick att öppna. Det ger registeruppgifter om organisationer.
- **Hur det fungerar (enligt tredjepart):** OAuth2 med klientuppgifter efter en gratis registrering; anropen ska göras från en server; 60 anrop per minut; scopes `vardefulla-datamangder:read` och `vardefulla-datamangder:ping`. Fält som organisationsnamn, organisationsform, registreringsdatum, SNI och dokumentlistor för digitalt inlämnade årsredovisningar. Ett betalt API (Företagsinformation v4) finns vid sidan av.
- **Kvalitet och underhåll:** myndighetens tjänst. Wrappers som MCP har 0–2 ★ och ingen eller okänd licens och tas inte in.
- **Det bästa vi kan ta:** juridiskt namn, organisationsform och organisationsnummer innan intervjun. Det avgör om organisationsnumret ska stå i sidfoten (bolag ja, enskild firma nej; `BESLUT.md` 2026-10-16, *Företagsuppgifter som praxis*).
- **Var det hamnar hos oss:** som källa i skillen `strategi`, `research.md`, märkt ⚠️, och som åtkomst i N2 när villkoren är lästa i primärkälla. I N1 frågas kunden.
- **Passar vår stack?** Ja tekniskt: en egen tunn klient i Python eller en Worker med klientuppgifterna som hemlighet utanför repot. Svaren är på svenska.
- **Risker och flaggor:** villkoren, avgiften och om enskilda näringsidkare ingår är overifierade. Enskilda firmor identifieras med personnummer, så deras uppgifter är personuppgifter (⚠️ inte stämt av mot IMY). Agenter kan inte läsa bolagsverket.se på grund av CAPTCHA.
- **Inloggning:** registreringen i API-portalen kräver konto, och CAPTCHA:n hindrar automatisk läsning. Johnny behöver läsa villkoren i webbläsaren och registrera byrån.
