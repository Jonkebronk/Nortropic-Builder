Every tool here gives a yes or no decision to the Jev model so Claude doesn't have to make that call itself. Here's what each one does:

Toolgate: Before Claude takes any action, Toolgate asks Jev whether it's allowed. It's stricter than Claude Code's Auto Mode. It blocks actions you can't undo, prompt injection attacks, downloaded tools that try to send your data to an outside server, and permissions you never gave Claude. It also stops Claude from doing work outside the task you gave it. In our test it caught a folder deletion with a 77% destructive risk score. It works with TypeSafe's own key, OpenRouter, or Vercel's AI Gateway.

Abide: Turns your AGENTS.md and CLAUDE.md files into a rubric of yes or no questions. It then checks every edit Claude makes against your rules, and Claude has to fix every flag before it can finish. Jev answers each check in about a second. It works with Claude Code and Codex.

Jev Browser: An open source browser testing tool. Claude runs the tests and Jev makes the yes or no calls. At the end you get a report listing every bug it found. Our test took about 2 minutes.

Jev Belay: Stops Claude from saying a task is done when it isn't. Jev reads the whole conversation and looks for proof that the work was finished. If there's no proof, Claude has to go back and finish it.

Jev Steer or Queue: When you send a new message while Claude is still working, Jev decides whether it should steer the current work, wait in a queue, or interrupt right away.

Compact Adviser: Uses Jev to tell you when it's safe to compact so Claude doesn't lose important details from the session.

Quicksilver: Jev searches your files and gives Claude a shortlist, so Claude reads only the files it needs. In our test, Jev checked 37 files in about 2 seconds and saved Claude from reading around 67,000 tokens.

Jev SEO: Give it a web address and you get a PDF SEO report with a score for each area, an Excel tracker of fixes, and a check on whether your site is ready for AI search.
