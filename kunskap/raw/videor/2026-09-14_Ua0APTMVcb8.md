# Insane GitHub Repos That 10x Your Codex And Claude Code Setup

## Beskrivning (från YouTube)

AI agents like Claude Code can build most of what you ask for, but there's still a lot they can't do on their own. People have built tools that fix those gaps, and we went through them to find the ones that actually hold up. These eight changed how we work, and they all work with Claude Code.

This isn't about how to setup Claude Code from scratch. It's about what to add once you setup Claude Code and want better results. Every repo here is free to install, so this is a free Claude Code setup upgrade (you still need access to Claude Code itself). Several of them are Claude Code skills, which are instructions your agent follows for a specific kind of task.

The 8 repos we cover:

1. img2threejs: Turns an object from an image into a 3D model made entirely from code, so you can add it to your landing page, animate it, and let people interact with it. One of the top trending repos on GitHub. It burns a lot of tokens and takes a while, but you can keep asking the agent to improve specific parts.

2. Reticle: Stops the agent from calling an app finished when it isn't. It opens your app in the browser, uses it the way you would, and marks each check as worked, didn't work, or not enough information to tell. When something fails, it explains what went wrong so the agent can fix it.

3. Chisle: Makes the agent use fewer words and skip code the task doesn't need. In the author's own test, one task dropped from about 1,500 tokens to about 600. In Claude Code, it also trims tool output before the agent reads it.

4. UI-Skills: A library of design skills from different authors. Connect it as an MCP or use it from the terminal, and the agent finds the design skills that fit your prompt, so you don't have to install each one yourself.

5. Ouroboros: Works through the details of your app before building, asks you about any decision that changes what the app does, then checks the finished app against the plan and sends problems back to the agent to fix.

6. FWC SwiftUI Skills: Skills for iPhone apps. One covers Apple's real Liquid Glass buttons and menus in iOS 26, the other covers layouts for the iPhone Duo, Apple's new foldable.

7. Caliper: Tests whether your Claude Code skills actually help. It runs the agent with and without a skill, then shows which tasks the skill handles reliably and whether it's worth the extra tokens. It works for MCP servers and other instructions too.

8. Anti-Slop: Works like a spellcheck for the code your agent writes. It catches specific coding mistakes in JavaScript and TypeScript projects, so the agent fixes them without you reading the code.
