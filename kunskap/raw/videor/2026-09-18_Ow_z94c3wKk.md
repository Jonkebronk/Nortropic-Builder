Why AI-built sites look generic

- Models lean on the patterns they saw most during training, so Claude Code design falls back to the same safe layouts on every build
- Purple and blue on white, warm orange and cream: each model has a look, and once you have seen it across a few sites you recognise it instantly
- Most fixes are written rules, so Claude Code used to web design pages from markdown descriptions alone, never from a finished page it could actually look at

Claude design, Claude Code, and where references fit

- Claude code skill design files like Hallmark already give the model direction and check the page against the patterns models fall into
- We use those skills too, and the ones in our workflows ship inside our AI Labs Pro design system
- But a design skill Claude Code loads is still text, so it cannot show how the whole page looks when every component sits together
- Inspo closes that gap by handing the agent real sites, which is why Claude Code for website design stops guessing at style

What Inspo gives your agent

- A free MCP server from the author of Hallmark, no account and no API key needed
- 832 sites and 2,320 captured pages, curated by hand: landing pages, pricing pages, about pages and more
- Desktop and mobile captures of every site, so website design with Claude Code holds up on small screens
- 68 reference components like navigation menus and pricing sections, with the code available
- A design.md for every site with the exact colour values, fonts, text sizes and spacing

How it works under the hood

- The agent sends your brief through the recommend tool, and Inspo finds the layout that repeats across the closest matches
- It returns up to five examples using that layout, matching components, a suggested colour palette and up to three screenshots
- Filters for industry, page layout, and light or dark theme narrow a Claude Code website design request down to references that actually fit
- The agent studies only a few in detail, because every extra search eats context
- 15 tools show up after install, and it runs in user scope so it is available in every folder

The workflow we ran

- We prompted a fashion landing page and asked for style options before any building started
- The agent called Inspo on its own, expanded the prompt with style keywords, and studied around 24 sites
- It came back with three design directions, and we picked one before it wrote the page
- The result borrowed the hero from one site, the buttons from another and the product layout from a third, without copying any of them
- We checked every referenced site by link to confirm it was inspiration, not a clone
- Claude Code mobile app design is a different job, but the mobile captures meant the page still worked on a phone
- For motion we used the UI Skills MCP, which loaded Emil Kowalski's animation skill and Meng To's scroll animation skill

Where it misses

- Twice it returned references from unrelated industries: a coffee subscription brief came back with health and business sites
- Selecting the food and beverage filter fixed it and returned coffee sites
- Some screenshots have cookie or privacy popups covering part of the design, and the agent fills that section from its own guess
- Ask for design directions first so you can catch the drift and reprompt before the whole page is built

Who this is for

- Anyone vibe coding a site who wants it to stop looking like every other AI page
- Treat this as a Claude Code tutorial for design rather than an AI automation video, though the same MCP setup applies if you already run AI automation workflows with Claude AI
- Claude skills and Claude design references work better together than either does alone
