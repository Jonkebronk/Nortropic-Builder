What Jev AI is
- Jev is an AI model made by TypeSafe. It doesn't write answers out in text like Claude AI or GPT. It picks from a set of options: a yes or no, a list to choose from, or a score.
- Along with every pick it gives you a confidence value, a number that shows how sure it was.
- Each decision takes a fraction of a second, and you only pay for what you send. The answer it sends back is free.
- Jev can't write code or use tools, so it doesn't replace the model in Claude Code. It sits inside Claude Code as the decision maker.

How to setup Claude Code with Jev
- New signups on TypeSafe's own platform are paused, but Jev is also on OpenRouter and Vercel AI Gateway. We used Vercel AI Gateway.
- Create a key on the API Keys page inside AI Gateway and copy it right away, because Vercel only shows it once.
- Save it with the export command as an environment variable, so when you open Claude in that same terminal, Claude Code can find the key.

The seven Jev use cases we tested
1. Faster compaction: the Fast Jev Compaction plugin swaps the usual compaction summary for Jev decisions about what actually matters in your session. We adapted it to work with Vercel AI Gateway, and on our session compaction took under a second.
2. Jev as a judge: a hook runs whenever Claude edits the files that control who can access what, and asks Jev whether each rule in our docs has a test. Then Claude writes the missing tests from Jev's report.
3. Skill picker: a hook reads every one of your Claude Code skills and your prompt, then tells Claude which one skill to use, or none.
4. Faster Explore: a skill runs a keyword search, then Jev scores the files 20 at a time so Claude only opens the top few. It ranked 35 files in 1.6 seconds and put the right file first.
5. Cheap first pass before the review: Jev answers seven yes or no questions about a change. Small changes get one quick review round, and risky ones still get the full review.
6. Browser testing: a skill lists every button and link on the page and Jev picks the next click. We signed in as an admin, a manager and an employee to check each could only reach their own pages.
7. Rule enforcer: a hook sends Jev every edit along with the rules for that file. If Jev is at least 80% sure a rule is broken, the edit is blocked and Claude is told which rule it broke.
