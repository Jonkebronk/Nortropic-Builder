Shopify rebuilt their main mobile app, all 300 screens, with AI coding agents and an internal tool called Helix. They shared the method but never showed how it's done, so we retraced it and built our own Claude Code custom workflow, then tested it by adding features to an internal HR system app we were building.

In this Claude AI tutorial, we break down every step of the Claude Code agents workflow:

- Checkpoints: a Checkpoint Planner agent splits a big feature into small tasks, ordered from simplest to most complex. A simple viewer lets you review the plan in plain language before any building starts.
- Gate 1, Behavior: tests are planned and written before the code, and every test has to pass.
- Gate 2, UI Review: the app is compared against an HTML prototype and your design.md file. Shopify used Gemini for this; we used Claude subagents instead, with no Gemini or OpenAI models needed.
- Gate 3, Adversarial Review: one agent assumes the code is wrong and hunts for issues, a fixer agent fixes them, and they go back and forth until the code is approved.
- Gate 4, Human in the Loop: you test the feature yourself, and your feedback becomes new checkpoints plus a learnings file every agent reads.

A hook, borrowed from the Ralph loop idea, stops the agent from quitting before the gates pass. That's the difference between a rule the agent can forget and a gate it can't talk its way out of.

The whole thing runs as a dynamic workflow in Claude Code. One orchestrator hands out jobs to AI agents, each subagent starts with a fresh context window, and it only stops for you twice. It's not a "Claude Code just replaced my entire workflow" story, since you still approve the plan and test the result, but the gates never let unfinished work through.

If you're looking for Claude Code for beginners, this shows how to use Claude Code on big features without letting quality slip. Whether you want a React Native Claude Code agentic workflow for a mobile app or you're building for the web, the same loop applies to any AI coding project where you want AI coding agents held to your standards.
