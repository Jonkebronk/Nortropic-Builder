Claude mods let you add any feature you wish Claude Code had. We built 7 of them, from a prompt enhancer to a session monitor, and show how each Claude mod works and how it goes beyond Claude Code plugins, Claude plugins, and knowing how to add skills to Claude.

What Claude mods are
- Claude mods are a feature Anthropic added to Claude Code that lets you change how Claude Code looks and works, and add features it doesn't already have.
- They're basically plugins that run inside Claude Code. A mod can draw its own panel beside the chat, add a strip with buttons above the prompt box, or redraw parts of Claude Code's own screen.
- How mods in Claude differ from a Claude skill or Claude plugins: a mod is always running and does its job every single time, like a built-in feature, and it can change what Claude Code does instead of only adding to it.
- Mods don't replace the skills, plugins, or Claude MCP setup you already have. They change Claude Code itself.
- Two mods Claude Code already ships with: the diff command, and You Should Know, a side agent that flags details you might miss in a long session (it's off by default).
- Mods that change the interface show up when you run Claude Code in the terminal, not in the VS Code extension.
- People share their own Claude Code mods at claudemod.com, so you can try what others have built.

Claude mods tutorial: how to use Claude mods
- On the latest Claude Code version, a built-in plugin authoring skill already knows how to build mods, so Claude makes mods from a plain prompt describing what you want.
- All the mods Claude wrote for us here started as a prompt. Claude loads the skill on its own and writes all the code.
- Allow hot reload when Claude Code asks, so the mod loads as soon as Claude finishes its turn and you can check it right away.
- A new mod only works in the session it was made in. Once it works the way you want, ask Claude to install it so all your new sessions can use it.

The 7 best Claude Code mods we built
- Prompt Enhancer: rewrites a rough prompt right in the prompt bar. It names the installed skills Claude should load, lists the big choices Claude should ask you about first, and says what the finished result should look like.
- Design Picker: when Claude asks you to choose a design style, the mod opens a site showing what each style looks like, so you pick by seeing instead of reading.
- Assumption Check: shows the small guesses Claude made during a task. Mark each one right or wrong, and the wrong ones go back to Claude to fix.
- Idea Shelf: park ideas while Claude works, without pulling it off the task. Each project gets its own shelf, ideas stay saved after you close Claude Code, and you send them to Claude as prompts later.
- Session Monitor: shows every running Claude Code session, which ones are waiting on you, which one is working, and which are done.
- Same-Folder Session Tracker: when two sessions work on the same project, each one shows what the other is doing, so they don't undo each other's work.
- Plain-English Claude Code: turns Claude's answers into simple language, moves all text to the summary at the end, adds next steps, and shows a status line of what the session is working on. A Haiku model checks the rules are followed.
